# AI 训练师题库 - H5 答题学习应用

移动端友好的答题练习工具，基于题库分类 JSON 构建，无需后端与构建工具，纯静态页面即可运行。

## 功能

- **按分类学习**：支持三级分类导航（七大类别 → 机器学习细分 → 三级细分）
- **答题练习**：单选 / 多选 / 判断 / 简答四种题型，即时判分与答案反馈
- **错题本**：答错的题自动收录，支持重做全部错题
- **已会题目**：答对的题自动标记为「已会」，可随时回顾
- **学习统计**：累计作答、正确率、各分类进度，可一键清空记录
- **练习设置**：按「全部 / 错题 / 未做 / 未会」筛选，支持顺序 / 随机，可选 20/50/100 题
- **随机练习**：从全部题库随机抽 20 题

## 目录结构

```
h5/
├── index.html          # 入口页面
├── style.css           # 样式
├── app.js              # 应用逻辑（原生 JS，无依赖）
└── data/
    ├── categories.json # 分类树（含各分类题数）
    └── q_*.json        # 按大类拆分的题目数据（7 个文件）
```

## 运行

由于需要 `fetch` 加载 JSON 数据，不能直接用 `file://` 打开，任选其一：

```bash
# 方式一：Python
cd h5 && python3 -m http.server 8000
# 浏览器访问 http://localhost:8000

# 方式二：Node
cd h5 && npx serve .
```

也可部署到任意静态托管（GitHub Pages / 飞书妙搭 / Nginx 等），把 `h5/` 目录整体上传即可。

## 数据说明

- 数据由根目录 `generate_h5_data.py` 从 `classified.json` 生成。
- 每道题字段：`n`（原题号）、`s`（题干）、`o`（选项 `[[字母,文字],...]`）、`a`（答案）、`t`（题型 1单选/2多选/3判断/4简答）、`c`（大类 id）、`sub`/`sub2`（机器学习细分）。
- 判断题答案统一为「正确 / 错误」；简答题无标准答案，答题时自我评估。
- 学习记录（错题、已会、统计）保存在浏览器 `localStorage`，更换设备/清除缓存会丢失。

## 重新生成数据

修改根目录分类后重新生成：

```bash
python3 generate_h5_data.py
```
